# Legacy (v1)

The original public demo of the document scanner, kept unchanged for reference:

- `app_v1/`: Flask app (upload → corner detection → NER predictions) with its trained spaCy model
- `business_card_/`: notebooks for OCR, data preparation, BIO labelling and training, plus the labelled dataset
- `flow/`, `intro/`: planning and architecture diagrams

v1 was built following the course *"Intelligently Extract Text & Data from Document with OCR NER"*. See the main README for the v2 rebuild and the label-scheme fix.
